# CineScape 3D

Windows 本地电影播放器：实时生成影院墙壁、舞台、立体酒红座椅与暖色壁灯，通过前后移动透视摄像机改变银幕视觉大小。没有账号、云服务或运行时联网依赖。

## 开始使用

已生成 Windows x64 程序：`Builds/Windows-Cinema/CineScape3D.exe`。分发包为 `Builds/CineScape3D-Windows-x64-Cinema.zip`，请完整解压后双击 EXE，保留旁边的 Data、DLL、MonoBleedingEdge 等文件。运行程序无需安装 Unity Editor，也无需 Unity 账号。

修改源码时使用 **Unity 6 LTS 6000.0.23f1**。本机编辑器位于 `D:\CineScapeBuildTools\Unity-6000.0.23f1\Editor`，可在 Unity Hub 中 Locate 添加。添加当前项目根目录，打开已生成的 `Assets/Scenes/Cinema.unity`，按 Play。需要重建配置时选择 `CineScape > 初始化项目`。详情见 [BUILD.md](BUILD.md)。

构建后保留整个 Windows 输出目录，双击 `CineScape3D.exe`，目标电脑无需安装 Unity Editor。

## 操作

点击“打开视频”选择本地 MP4 或 MKV。MKV 使用随程序携带的 LibVLC 直接解码，打开后按需读取并播放，不再整片转码，也不生成临时影片；原文件不变。画面按比例送到 1080p 银幕，音频由同一解码后端同步输出。字幕和其他音轨不会显示或切换。MP4 直接由 Unity 和 Windows 解码，兼容性仍取决于文件编码。加载有提示及 30 秒超时；无声视频也可显示画面。银幕使用 Unlit 材质与 1080p RenderTexture，宽高比采用 FitInside 留黑。

控制栏提供播放/暂停、停止、拖动进度、当前/总时长、音量、静音、全屏与设置。停止后清空画面，按播放重新准备当前文件并从头播放。播放结束保持影院与末帧，再按播放重新开始。拖动进度在释放时跳转；某些编码的精确跳转能力受解码器限制。

滚轮向上靠近、向下远离；距离滑块 0% 最远、50% 初始、100% 最近。摄像机位于中央座位区，随阶梯高度前后平滑移动，过道在两侧。点击“银幕校正”调整 0%～100%；默认 100% 自动校正为矩形，0% 保留原始透视。校正随距离和窗口比例更新，设置自动保存。滚轮在 UI 上不移动摄像机，避免误操作。播放时无操作约 3 秒隐藏控制栏，移动鼠标恢复；悬停控件、暂停、拖动或打开设置时保持显示。

| 快捷键 | 功能 |
|---|---|
| Space | 播放/暂停 |
| Ctrl+O | 打开视频 |
| Left / Right | 后退/前进 5 秒 |
| Up / Down | 音量增减 5% |
| F / Esc | 切换全屏 / 退出全屏 |
| Home | 恢复设置中的默认观看距离 |

设置面板打开时暂停播放器快捷键；文本输入编辑时不处理播放器快捷键。全屏使用 Windows 无边框全屏。

## 设置与故障

设置支持低/中/高画质（默认中）、启动全屏、默认音量、默认距离、记住距离、控制栏自动隐藏。运行音量与距离变化每秒保存一次，退出时保存。配置位于 `%USERPROFILE%\AppData\LocalLow\CineScape\CineScape3D\settings.json`，损坏时恢复默认值。当前只有简体中文；`language` 字段预留后续语言资源，尚未实现日语/英语翻译。字体从 Windows 微软雅黑读取，不附带字体文件。

- 视频加载失败：检查文件存在，尝试标准 H.264/AAC MP4；MKV 请检查完整 VLC DLL 和 plugins 目录，查看 Unity Player.log；不支持的格式不会导致应用主动退出。
- 黑屏/粉色：先执行初始化菜单，确认 URP 包导入成功；构建中已包含运行时使用的 Shader。
- 没有声音：检查静音、音量及 Windows 音频输出设备。
- 卡顿：切换低画质、关闭其他 GPU 密集程序；4K 源视频仍可能有高解码负载，即使纹理输出为 1080p。
- 设置无法保存：确认 LocalLow 可写，查看日志中的配置错误。

真实 Unity 编译、Windows x64 构建、EXE 启动、配置/摄像机 EditMode 测试与 H.264/AAC PlayMode 播放测试已完成。人工 UI 操作、不同 DPI、长时间音画同步与性能指标尚未验收，详见 [DEVELOPMENT.md](DEVELOPMENT.md)。



影院加入墙柱、顶梁、灯带、两侧阶梯过道和更清楚的座椅明暗。观看距离 25%～50% 可以看见更多内部空间；靠近银幕则增加影片占比。
